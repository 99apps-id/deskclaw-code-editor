# Product

## Register

product

## Users

Developers and technical operators using OpenClaw on Windows. They work inside a
desktop coding workflow and need files, terminal, Git, model configuration, and
agent collaboration in one dependable application.

## Product Purpose

DeskClaw turns the OpenClaw runtime into a practical desktop code editor. Success
means users can install, configure, connect, edit, run, debug, version, and
delegate work without falling back to manual terminal setup or disconnected
configuration screens.

## Brand Personality

Precise, capable, and calm. The interface should feel like a trusted developer
tool, not an AI showcase.

## Anti-references

- Generic AI dashboards, glowing assistant robots, and decorative gradients.
- Read-only editor mockups or controls that do not execute real operations.
- Card-heavy settings pages and inconsistent panel behavior.
- Hidden failures, silent file errors, and destructive actions without review.

## Design Principles

- Function earns every visible control.
- Keep code and workspace context central.
- Reuse OpenClaw rather than disguising or reimplementing it.
- Make failure explicit, recoverable, and useful.
- Follow familiar desktop-editor interaction patterns.

## Accessibility & Inclusion

Target WCAG AA contrast for UI text, full keyboard focus visibility, semantic
labels for icon controls, reduced-motion support, and state communication that
does not depend on color alone.
